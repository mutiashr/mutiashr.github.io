01
K-Means Clustering for F1 Driver Performance Analysis (2024)
Jurnal Buffer Informatika · October 2025 · Lead Researcher
+
CONTEXT
The 2024 Formula 1 season generated a rich dataset of race-level performance metrics across the full grid. The question was simple: can unsupervised learning uncover performance patterns that conventional race commentary might overlook?
APPROACH
K-Means clustering with Elbow Method applied to normalized race metrics. Silhouette Scoring validated the cluster separation. Output translated into a live Streamlit dashboard.
RESULT
4 distinct performance tiers identified across the 2024 grid. Silhouette Score 0.5735. Published October 2025. Live dashboard + Colab notebook publicly available.

02
ML Algorithm Comparison for Cosmetic Sales Prediction
JURTEKSI · September 2025 · Thesis Research
+
CONTEXT
Tokopedia cosmetic sales data has a structural class imbalance, where bestsellers dominate and minority-class prediction becomes unreliable. This study compares four classification approaches instead of relying on a single algorithm.
APPROACH
SMOTE applied for class balancing. 4 classifiers trained: Random Forest, XGBoost, Logistic Regression, Naive Bayes. GridSearchCV for hyperparameter tuning. Evaluated on Accuracy + F1-Score.
RESULT
Random Forest identified as superior model. 85.3% accuracy, F1-Score 0.75. Published September 2025.

03
LPG 3KG Distribution Clustering — Palembang Subsidy Equity Analysis
Jurnal Buffer Informatika · April 2025
+
CONTEXT
Indonesia's subsidized LPG (3kg) is critical for low-income households. Distribution managed by outlet networks across sub-districts. When outlet density doesn't match population density, some areas get systematically under-served.
APPROACH
K-Means clustering with Elbow Method across Palembang sub-districts. Pandas for data cleaning, Scikit-learn for clustering, Matplotlib for visualization.
RESULT
Identified suboptimal outlet-to-population ratios in high-density areas such as Sukarami, providing a data foundation for distribution planning and more targeted subsidy allocation. Published April 2025.

03
Yappy — Language Learning App
UX Lead (Research + Prototyping)
UI/UX ★ 3RD PLACE · SIFEST 2024 FIGMA UX RESEARCH
"A familiar problem with language learning apps: everyone gets pushed through the same learning path. Yappy explores a different approach: start with why you want to learn."
CONTEXT
SIFEST 2024 design competition. We explored a common gap in language learning apps: users have different reasons for learning, but many platforms still rely on a standardized level-by-level experience.
APPROACH
Explored goal-based learning through competitive analysis and user journey mapping. Yappy offers different learning modes based on user goals, including Classic, Speaking, Professional, Literature, and Travel.
The concept was extended with mentor-led courses, community discussions, podcasts, and video content to support different learning preferences.
RESULT
3rd place at SIFEST 2024. Designed a high-fidelity Figma prototype for Yappy, a personalized language learning app built around what users want to achieve, not just what level they are on.
VIEW PROTOTYPE →
REFLECTION
The strongest idea in Yappy was shifting the starting point from "What level are you?" to "Why are you learning?" If developed further, I would validate which learning goals users actually prioritize and whether goal-based paths improve engagement and learning outcomes.
